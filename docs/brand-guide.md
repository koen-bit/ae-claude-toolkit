# Martell Brand Style Guide — Extracted Values

## Typography

### Fonts
| Role | Font Name (PostScript) | Case | Usage |
|---|---|---|---|
| Primary | `BBNonamePro-Bold` | Sentence case | 80% of text |
| Secondary | `Bodoni 72-Book italic` | Sentence case | 20% of text |
| Tertiary | `Akkordeon-Nine` | ALL CAPS | Accent text |

### Font Location
NAS: `CL-000 (ASSETS) > 03 - miscellaneous > 03.2 - Fonts`

### Subtitles
- Use primary font (BBNonamePro-Bold)
- Apply adjustment layer on top

## Graphics Rules

### UI Accuracy
- 90%+ accuracy when recreating real interfaces (Google Calendar, social media, etc.)
- Never fake or approximate — rebuild faithfully

### Roadmaps (under 20 items)
- Numbered steps with connecting lines
- Glowing elements for emphasis
- Dark background

### Sub-Roadmaps (Progress Bar Style)
- **Layout:** Horizontal progress bar, centered in comp
- **Title:** White, primary font, centered above the bar
- **Completed section:** Solid teal line (`6EF8FD`), ~8-10px stroke, rounded caps
- **Remaining section:** Dashed grey line (`808080`), same stroke weight, evenly spaced dashes
- **Transition:** Solid line ends where progress stops, dashes continue for remaining items
- **Items:** Numbered, white, primary font, evenly spaced below the bar
- **Background:** Solid black/charcoal
- **Text effects:** Standard drop shadow on all text

### Tagging Overlays (IG handles)
- Must be pixel-identical every time — no variation

### Visual Style
- Dark backgrounds with subtle topographic wave patterns
- Visual metaphors encouraged (ladders for growth, chains for limitation, etc.)
- Glowing accents on key elements
